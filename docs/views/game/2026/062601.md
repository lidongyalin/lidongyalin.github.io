## 游戏简介

《黑神话：悟空》（Black Myth: Wukong）是由**游戏科学（Game Science）** 开发的一款动作角色扮演游戏，于 2024 年 8 月 20 日全球发售。游戏以中国古典名著《西游记》为蓝本，采用虚幻引擎 5 打造，讲述了取经之后的故事——天命人重走西游之路，寻回齐天大圣孙悟空遗落的六件根器，揭开尘封的真相。

> **鸿蒙初辟原无姓，打破顽空须悟空。**

## 核心特色

### 视听盛宴

- **顶级画质**：虚幻引擎 5 打造，真实扫描的中国古建筑遍布游戏各处
- **古建巡礼**：山西晋城玉皇庙、高平铁佛寺、隰县小西天、朔州崇福寺、恒山悬空寺、河北蔚县玉皇阁、天津蓟县独乐寺、云南大理崇圣寺等
- **音乐配乐**：中式民族特色的战斗配乐，每回片尾动画主题曲令人难忘
- **音效沉浸**：自然环境声、武器打击感、妖魔嘶吼、众生诘问

![中国古建筑场景](https://aka.doubaocdn.com/s/XVUG1wfucV)

### 战斗系统

- **三种棍法**：劈棍、立棍、戳棍，各有特色与切手技
- **七十二变**：狼、石、鼠、虎、蛸、猴、龙、虫、马、猿十种变身
- **法术系统**：定身法、聚形散气、铜头铁臂、身外身法、安身法、禁字法等
- **精魄系统**：五十五个精魄，吸收妖王能力为己所用
- **法宝装备**：避火罩、定风珠、锦襕袈裟等法宝各有用途

## 第一回：火照黑云

> **地点**：黑风山 · 观音禅院
> **根器**：眼见喜
> **对应**：贪
> **五蕴**：色蕴

### 故事背景

改编自原著第十六回、第十七回「观音院僧谋宝贝 黑风山怪窃袈裟 孙行者大闹黑风山」。

天命人的西游之路从黑风山开始。三口洪钟声起，因金池长老对袈裟生起的贪念，化作旧时的观音禅院，山中不住传来金池的呼唤。

### 主要剧情

#### 1. 观音禅院的兴衰

广智、广谋两个徒弟煽风点火，撺掇师公金池长老放火烧死取经人、谋取锦襕袈裟。结果宝贝没寻着，反倒烧了整个寺院。二百七十岁高龄的金池长老撞墙自戕，怨念化作幽魂四处游荡。

> **"可人心若是烧没了，修好一座破庙又有什么用呢？"**

黑熊精从南海归来后，试图重建观音禅院，超度死去的僧众、复原经书残卷。他赐名狼妖灵虚子扶持为王，却引发山中动乱；复活老友凌虚子，对方却上吊离去；还魂老和尚金池，反倒成了亡魂精怪。最终一切无功而返，黑熊精回到紫竹林。

#### 2. 黑熊精的执念

观音菩萨以去掉禁箍为由，点卯黑熊精完成一件差事。黑熊精受天庭胁迫出战，归来后回到黑风山，将得来的炼化不得的宝贝高高供在宝刹上，用来欺骗信众、敛财朝拜。

天命人降伏黑熊精后，宝物感应到天命人的存在，将携宝逃窜的黑熊精慑服于地，化为**重明鸟**飞到天命人手上——这是大圣的根器之一**眼见喜**。

### 章节动画·金池的一生

章末动画以工笔勾描的形式，讲述了金池长老的一生：

- 少年时的金池在树林里捉蛤蟆，偶遇黑熊精，结下佛缘
- 第一次听到《准提咒》，内心还保留着纯粹
- 看到高僧身上的袈裟，渐渐认为一定要有袈裟才能得道——**看见的是执念**
- "求不得，闭上眼"——求助黑熊精后终于披上袈裟，成为禅院院主
- 欲望日益增长，收集七八百件袈裟，以此为尊为荣——**看见的是欲望**
- 二百七十岁时见到锦襕袈裟，贪念彻底爆发
- "贪嗔痴，看见"——金池被欲望吞噬，火烧观音禅院
- 黑熊精本想救火，却也见财起意趁火打劫
- 皈依佛门后黑熊精问师父："长老为何偏偏放不下一件衣裳？"
- 观音答："若不披上这件衣裳，众生又怎知我尘缘已断，金海尽干？"

### 核心角色

| 角色 | 简介 |
|------|------|
| **金池长老** | 观音禅院院主，二百七十岁高龄，因贪慕锦襕袈裟而自焚 |
| **黑熊精** | 黑风山大王，后皈依佛门，本性不坏但难逃贪欲 |
| **广智 / 广谋** | 金池的徒弟，煽风点火教唆谋财害命 |
| **凌虚子** | 黑熊精老友，复活后上吊自尽 |
| **灵虚子** | 狼妖，被黑熊精扶持为王引发动乱 |

## 第二回：风起黄沙

> **地点**：黄风岭 · 斯哈哩国
> **根器**：耳听怒
> **对应**：嗔
> **五蕴**：受蕴

### 故事背景

改编自原著第二十回至第二十一回「黄风岭唐僧有难 半山中八戒争先 护法庄设斋留妙喜 猪年八戒忘形」。

天命人来到黄风岭，黄沙漫天，风沙蔽日。灵吉菩萨化身的无头说书人一路相助，梅山黄袍员外指引天命人穿越回过去的斯哈哩国——一切悲剧的起点。

### 主要剧情

#### 1. 斯哈哩国的诅咒

灵吉菩萨一怒之下，降下蝮蝂巨虫惩戒斯哈哩国，又降下诅咒将国民变为老鼠。曾经为民灭虫的**黄风大圣**（黄毛貂鼠），日后却变成了为报复而砍下师父头颅的**黄风怪**。

> 一个人的嗔，会引起另一个人的嗔——这是因嗔而起的悲剧。

沙国王推行「敬鼠令」，将反对的臣子尽数诛杀——**天子一怒**。
沙大郎因不满父亲而产生癔症；沙二郎在父亲死后进入暴怒状态；沙三郎不满政策远走西方，落得在浮屠牢中残疾度日——**这是因嗔而起的悲剧其二**。

#### 2. 虎先锋一家

虎先锋不满黄风怪却又打不过，选择跪下投降，和兄弟分道扬镳，每日吃鼠解恨。
疯虎不满兄长下跪，实力不济却被打伤，找了个虎伥吃人养伤。
定风庄村民愤怒于虎伥所为，把他儿子打死；虎伥一怒之下血洗定风庄，整日在风沙里的桥上疯疯癫癫——**这是因嗔而起的悲剧其三**。

因嗔怒而起的报复、镇压、打杀，最终只会打在自己身上。

#### 3. 黄风大圣的陨落

天命人穿越到过去的斯哈哩国，与侠义豪迈的黄风大圣合力击败灵吉菩萨的坐骑，拯救了斯哈哩国人民，获得法宝**定风珠**。

然而过去无法改变。回到现在，天命人最终击败了陷入疯狂的黄风大圣，取得大圣根器——**耳听怒**。

### 章节动画·定格布偶

第二回片尾采用定格布偶风格，讲述了黄风岭的悲剧轮回。黄沙掩埋了一切，愤怒的风暴永不停歇。

### 核心角色

| 角色 | 简介 |
|------|------|
| **黄风大圣 / 黄风怪** | 黄毛貂鼠，曾为民除害，后因嗔怒堕落为妖 |
| **灵吉菩萨** | 降下灾祸惩戒斯哈哩国，化身无头说书人 |
| **沙国王** | 斯哈哩国国王，推行敬鼠令，刚愎自用 |
| **沙大郎 / 沙二郎 / 沙三郎** | 沙国王的三个儿子，各有悲剧 |
| **虎先锋 / 疯虎 / 虎伥** | 三兄弟，因嗔怒而家破人亡 |
| **黄袍员外** | 梅山兄弟之一，指引天命人穿越时空 |

## 第三回：夜生白露

> **地点**：小西天 · 新雷音寺
> **根器**：鼻嗅爱
> **对应**：慢
> **五蕴**：想蕴

### 故事背景

改编自原著第六十五回至第六十六回「妖邪假设小雷音 四众皆遭大厄难 诸神遭毒手 弥勒缚妖魔」。

天命人踏入银装素裹的小西天，这里是黄眉老佛的领地。黄眉本是弥勒佛面前司磬的童子，却想代替弥勒成为未来佛，建立自己认知中的极乐世界。

### 主要剧情

#### 1. 黄眉的傲慢

黄眉看不起佛门戒律，看不起天命人，更看不起茫茫众生。他自认为能建立比西天更美好的极乐世界，在新雷音寺中称王称帝。

> **傲慢，是最大的愚昧。**

第三章的各色人等，都是被「慢」误导了想，做出了错误的判断，最终导致悲剧。

#### 2. 各路英豪的折戟

- **小张太子**：明明在原著里吃过黄眉的亏，第二次仍不考虑后果莽撞冲进陷阱，害死了四健将，自己也眼瞎耳聋，无家可归。
- **亢金龙**：为查昴日星官下落，既不事先安排也不召集援手，莽撞冲进黄眉陷阱，最终被蛊惑洗脑。
- **无量蝠与剑客**：剑客因村民的感谢与财宝而自满，答应去杀另一只无量蝠，结果被拖入黑暗再无声息——死于傲慢。

#### 3. 小雷音寺之战

天命人一路披荆斩棘，经历了雪岭路径、浮屠界、极乐谷、苦海等区域，最终抵达新雷音寺。

与黄眉的大战惊心动魄——黄眉手持金铙、狼牙棒，还有人种袋等法宝，实力强横。最终天命人战胜黄眉，取得大圣根器——**鼻嗅爱**。

### 章节动画·华丽精美

第三回片尾动画华丽精美，展现了小西天的冰雪琉璃世界与黄眉的野心。

### 核心角色

| 角色 | 简介 |
|------|------|
| **黄眉老佛** | 弥勒童子，自立为佛，傲慢是他的原罪 |
| **小张太子** | 泗州大圣国师王菩萨弟子，莽撞自大 |
| **四健将** | 小张太子的部下，死于黄眉之手 |
| **亢金龙** | 二十八宿之一，被黄眉蛊惑 |
| **弥勒佛** | 未来佛，黄眉的师父 |

## 第四回：曲度紫鸳

> **地点**：盘丝岭 · 紫云山
> **根器**：舌尝思
> **对应**：痴
> **五蕴**：行蕴

### 故事背景

改编自原著第七十二回至第七十三回「盘丝洞七情迷本 濯垢泉八戒忘形 情因旧恨生灾毒 心主遭魔幸破光」。

天命人来到盘丝岭，这里蛛网密布、毒雾弥漫。盘丝洞的七位蜘蛛精姐妹，各有各的故事，各有各的痴情。

### 主要剧情

#### 1. 百眼魔君的痴

百眼魔君（蜈蚣精）一方面做昆仑的狗，把身边小妖卖给昆仑炼丹换取赏赐，协助天庭迫害昴日星官，却完全没想过「狡兔死，走狗烹」的道理。他死前还在叫「师尊快来救我」。

另一方面，他又觉得拿到了大圣根器就可以脱离昆仑掌控，却不曾想过，就算是孙悟空，也在天庭的围攻下身死道消。

> 不明事理，是非不分——这就是痴。

#### 2. 紫蛛儿的痴

紫蛛儿是最让玩家泪目的角色。她痴恋八戒，为了追随他私自下凡，投胎成蜘蛛。为了见八戒一面，她不顾身体伤情，借用**舌尝思**续命——据说吃了八戒就能恢复身体，可她终究下不去手。

她临死前那句「你还是和那时一样……笨呐！」道尽了一生痴情。

> 她是痴，但她的痴，是心甘情愿。

#### 3. 七姐妹的命运

盘丝洞七位蜘蛛精姐妹，性格各异，命运各殊。她们的故事交织在一起，构成了盘丝岭的凄美传说。

天命人最终在紫云山千花洞击败百眼魔君，取得大圣根器——**舌尝思**。

### 章节动画·揪心闪回

第四回片尾动画以揪心的闪回方式，展现了蜘蛛精姐妹们的往昔岁月与悲惨结局，令人潸然泪下。

### 核心角色

| 角色 | 简介 |
|------|------|
| **紫蛛儿** | 七蜘蛛之一，痴恋八戒，最令人动容的角色 |
| **百眼魔君** | 蜈蚣精，多目怪，阴险狡诈却又愚蠢 |
| **蜘蛛七姐妹** | 盘丝洞七位蜘蛛精，各有性格 |
| **猪八戒** | 天蓬元帅转世，与紫蛛儿有旧情 |
| **昴日星官** | 天庭星宿，被百眼魔君协助迫害 |

## 第五回：焰熔残阳

> **地点**：火焰山 · 丹灶谷
> **根器**：身本忧
> **对应**：疑
> **五蕴**：识蕴

### 故事背景

改编自原著第五十九回至第六十一回「唐三藏路阻火焰山 孙行者一调芭蕉扇 猪八戒助力败魔王 孙行者三调芭蕉扇」。

天命人来到炽热的火焰山，这里是当年孙悟空大闹天宫踢翻太上老君炼丹炉落下的余火所化。牛魔王一家的悲剧，在这里上演。

### 主要剧情

#### 1. 牛魔王的疑

牛魔王是平天大圣，是孙悟空的结义大哥。然而他对孙悟空充满了疑虑——当年的结义是否只是利用？自己的兄弟究竟是什么人？这份怀疑，让他走向了悲剧。

> **疑，是五毒之末，却也是最难解的。**

红孩儿被观音收为善财童子，铁扇公主在翠云山守着活寡，牛魔王在外面有了玉面狐狸——曾经威震一方的平天大圣，家不成家。

#### 2. 红孩儿的执念

红孩儿（圣婴大王）一心想证明自己，想得到父亲的认可。他修炼三昧真火，却最终被观音收走，与家人分离。

火焰山下，红孩儿的故事以另一种方式延续。天命人在丹灶谷中与红孩儿相遇，见证了他的执念与不甘。

#### 3. 火焰山终战

天命人穿越火海，击败一众妖王，最终与牛魔王展开大战。牛魔王实力强横，拥有多种形态变化。

战胜牛魔王后，天命人取得大圣根器——**身本忧**。前五回的五件根器全部集齐，真相即将揭开。

### 章节动画·热血酷炫

第五回片尾动画热血酷炫，火焰与铁拳交织，展现了牛魔王的霸气与悲情。

### 核心角色

| 角色 | 简介 |
|------|------|
| **牛魔王** | 平天大圣，孙悟空的结义大哥，充满疑虑 |
| **铁扇公主** | 罗刹女，牛魔王之妻，手持芭蕉扇 |
| **红孩儿** | 圣婴大王，牛魔王与铁扇公主之子 |
| **玉面狐狸** | 牛魔王的小妾，万岁狐王之女 |
| **如意真仙** | 牛魔王的弟弟，聚仙庵庵主 |

## 第六回：翠显丹霞

> **地点**：花果山 · 水帘洞
> **根器**：意见欲
> **对应**：意
> **五蕴**：五蕴皆空

### 故事背景

天命人集齐五件根器，来到大圣的故乡——花果山。这里是孙悟空出生成长的地方，也是一切的起点与终点。

最终的真相，将在水帘洞中揭晓。

### 主要剧情

#### 1. 花果山的凋零

曾经生机勃勃的花果山，如今一片凋零。猴子猴孙们的命运令人唏嘘。天命人在这里遇到了各种故人——有的还在等待大圣归来，有的已经放弃了希望。

> **花果山，是起点，也是终点。**

#### 2. 真相揭晓

随着最后一件根器**意见欲**的获得，六根齐聚，真相终于浮出水面。

天命人究竟是谁？孙悟空是生是死？取经之后究竟发生了什么？所有的谜题，在这一章中一一解开。

- 大圣的六根为何散落人间？
- 天庭与西天之间有怎样的博弈？
- 天命人的使命究竟是什么？

#### 3. 最终之战

花果山的最终决战，是对玩家的终极考验。石猿、法天象地，真假猴王……一场场惊心动魄的战斗，将故事推向高潮。

而故事的结局，取决于玩家的选择——是走向既定的命运，还是打破轮回？

### 隐藏结局

游戏有多个结局，真隐藏结局需要在前五回中完成特定的支线任务才能解锁。达成条件后，第六回会出现不同的剧情走向。

### 章节动画·写意水墨

第六回片尾动画采用写意水墨风格，大气磅礴又充满禅意，为整个故事画上圆满（或不圆满）的句号。

### 核心角色

| 角色 | 简介 |
|------|------|
| **孙悟空** | 齐天大圣，他的命运是游戏最大的谜题 |
| **天命人** | 玩家所扮演的角色，身份成谜 |
| **二郎神** | 显圣真君，梅山兄弟的首领 |
| **梅山六兄弟** | 二郎神的部下，贯穿全文的线索人物 |
| **土地公** | 每一章都出现的神秘老人 |

## 游戏评价

### 优点

- **画面顶级**：虚幻引擎 5 带来的视觉享受，中国古建还原度极高
- **配乐优秀**：国风音乐出色，每回主题曲都堪称经典
- **战斗丰富**：棍法、法术、变身、精魄、法宝，玩法多样
- **叙事深刻**：不只是打怪升级，每一章都有对人性与佛理的探讨
- **诚意满满**：内容充实，六回主线加大量隐藏内容

### 不足

- **地图引导**：缺少小地图，容易迷路
- **难度曲线**：部分 Boss 难度跳跃较大
- **优化问题**：发售初期存在一些性能问题

## 写在最后

《黑神话：悟空》不仅仅是一款游戏，更是一次对中国传统文化的深度挖掘与创新演绎。它让我们重新审视《西游记》这部经典，重新思考「悟空」二字的含义。

> **记得盂兰会上，世尊说过：众生之苦，多因不守戒律、放情纵欲。**

前五回讲的是贪嗔慢痴疑——众生之苦。
第六回讲的是——能否打破顽空，真正悟空。

愿每一位天命人，都能在这段旅途中，找到属于自己的答案。

**金猴奋起千钧棒，玉宇澄清万里埃。**
