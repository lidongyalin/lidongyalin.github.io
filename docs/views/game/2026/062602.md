## 游戏简介

《碧蓝航线》（アズールレーン / Azur Lane）是由中国上海**蛮啾网络**与**勇仕网络**联合开发的二次元舰娘养成类手游，于 **2017年5月25日** 正式上线中国大陆服务器。游戏以架空的第二次世界大战为背景，将历史上的各类军舰拟人化为性格各异的少女角色，玩家扮演「指挥官」，带领舰娘们在浩瀚的海洋上展开冒险。

> **为了那片碧蓝之海！**

## 世界观与背景

### 故事背景

在一个海洋占了 71% 表面积的蓝色星球上，人类文明伴随着海域的开发而蓬勃发展。然而，一切的平静被突然出现在海洋中的未知敌人——拥有压倒性战力的神秘敌人**「塞壬」** 所打破。人类失去了超过 90% 的海域控制权，被拖入了深海的黑暗之中。

为了合力抵抗塞壬、夺回海洋，**白鹰、皇家、铁血、重樱** 四大阵营摒弃前嫌，联合起来组成了第三方军事抗争阵线——**「碧蓝航线」**。

然而，随着战争的推进，铁血与重樱受到塞壬的影响，最终退出并背叛了碧蓝航线，建立了对立的**「赤色中轴」**阵营。人类的内斗让本就艰难的抗敌事业雪上加霜……

玩家扮演的「指挥官」将加入碧蓝航线，带领舰娘少女们，在碧海蓝天之间，为人类的未来开辟新的道路。

### 两大阵营

#### 碧蓝航线（Azur Lane）

由**白鹰、皇家、东煌、北方联合、自由鸢尾、撒丁帝国（后加入）**等阵营组成，主张以人类自身的力量对抗塞壬，坚持人类的尊严与自由。

#### 赤色中轴（Crimson Axis）

由**铁血、重樱、维希教廷**等阵营组成，受塞壬技术的诱惑，选择了借助塞壬的力量来「进化」人类的道路。

#### 塞壬（Siren）

拥有压倒性科技实力的神秘敌人，是全人类共同的威胁。她们的目的与来历至今成谜，似乎在进行着某种「实验」……

## 游戏玩法

### 核心玩法循环

《碧蓝航线》的核心玩法围绕**「收集养成 → 编队配置 → 关卡挑战 → 资源获取 → 养成升级」**展开，形成完整的养成闭环：

1. **建造/打捞/活动** 获取舰船角色
2. **消耗资源** 提升等级、强化装备、突破界限
3. **配置编队** 挑战主线关卡、活动副本、Boss 战
4. **获取更多资源和新角色**，继续养成

![碧蓝航线角色展示](https://picsum.photos/seed/azurlane-characters/800/450)

### 战斗系统

#### 双排式编队

舰队分为**前排先锋舰队**和**后排主力舰队**，最多 6 艘舰船协同出战：

- **前排（先锋）**：驱逐舰、轻巡洋舰、重巡洋舰
  - 负责扛伤、输出鱼雷、近身作战
  - 玩家手动操控移动和闪避
- **后排（主力）**：航空母舰、战列舰、战巡、重炮
  - 负责远程火力输出、航空支援
  - 自动攻击，玩家手动释放必杀技

#### 即时弹幕射击

战斗采用**横向卷轴弹幕射击**模式：

- **左手操控**：控制前排旗舰移动，躲避敌方弹幕
- **右手操控**：手动瞄准、释放技能
- **自律战斗**：自动战斗模式，适合日常推图
- **手动操作**：适合挑战高难度 Boss

### 养成系统

#### 1. 等级与突破

- **升级**：通过战斗或经验书提升等级
- **突破**：消耗同名舰船或通用布里，提升稀有度和属性
- **改造（改二）**：部分舰船可以进行现代化改造，大幅提升实力和改变立绘

#### 2. 技能系统

每艘舰船拥有 1~3 个独特技能，技能可以升级强化：

- **主动技能**：手动释放的大招，如全弹发射、空袭等
- **被动技能**：常驻增益或触发效果，如增加伤害、减伤等
- **阵营技能**：同阵营组队时触发的连携效果

#### 3. 装备系统

装备分为五大类，不同舰种适配不同装备：

- **舰炮**：主力输出武器，战列/重巡使用
- **鱼雷**：高爆发伤害，驱逐/轻巡/潜艇使用
- **防空炮**：对抗敌方舰载机
- **舰载机**：航母专用，战斗机/轰炸机/鱼雷机
- **设备**：各种辅助装备，增加属性或特殊效果

#### 4. 好感度与誓约

- **好感度系统**：通过一起出战、互动提升好感度
- **好感度等级**：陌生 → 友好 → 喜欢 → 爱 → **誓约**
- **誓约系统**：好感度达到「爱」后，可以使用「誓约之戒」与舰娘结婚
- **誓约加成**：属性提升、专属立绘、特殊语音、纪念日

### 主要游戏模式

#### 1. 主线剧情

推进世界观剧情，解锁新海域和功能，是获取基础资源和常规舰船的主要途径。每个大章节包含多个小关卡，最终挑战章节 Boss，有概率掉落限定舰船。

#### 2. 限时活动

游戏平均每月推出一期**大型主题活动**，包含：

- 全新剧情章节
- 限定建造池（限定角色）
- 活动关卡掉落
- 活动商店兑换
- 活动任务奖励

是玩家获取限定角色和皮肤的核心渠道。

#### 3. 大舰队（公会）

类似公会系统，玩家加入大舰队后可以参与：

- 舰队 Boss 挑战
- 联合研发
- 港口建设
- 舰队商店兑换
- 社交互动

#### 4. 演习（PVP）

异步 PVP 玩法，玩家配置进攻编队挑战其他玩家的防御编队，根据排名结算奖励，每周重置排名。

#### 5. 潜艇系统

派遣潜艇执行秘密任务获取稀有资源，在主线关卡中也可以召唤潜艇进行伏击，对 Boss 造成额外伤害。

#### 6. 后宅系统

舰娘的休闲生活区：

- **宿舍**：数百种家具自由 DIY，打造专属港区
- **食堂**：制作料理，回复舰娘心情
- **浴场**：泡澡恢复疲劳
- **互动**：触摸、对话、送礼，增加好感度

#### 7. 委托系统

派遣舰娘执行各种委托任务，挂机获取资源和经验，是日常资源获取的重要途径。

## 剧情介绍

### 序章：指挥官上任

玩家作为新任指挥官来到碧蓝航线的母港，与初始舰娘（拉菲、标枪、Z23 三选一）相遇，开始了指挥舰队的生涯。随着塞壬的不断来袭，指挥官逐渐深入了解这场战争的真相。

### 第一章：觉醒的战列

碧蓝航线在某海域遭遇铁血舰队的袭击，指挥官首次带领舰队迎战。战斗中，玩家了解到铁血退出碧蓝航线、加入赤色中轴的经过，以及塞壬在其中扮演的神秘角色。

### 第二章：闪耀的追踪者

皇家舰队在北大西洋追踪铁血舰队，胡德与威尔士亲王登场。俾斯麦的传说开始浮现，玩家见识到了铁血战列舰的强大实力。

### 第三章：包围网的危机

重樱舰队开始大规模行动，赤城、加贺等一航战登场。碧蓝航线在太平洋上与重樱展开激烈交锋，玩家逐渐发现重樱背后似乎有着更大的阴谋。

### 第四章：跨越的悲伤

中途岛海域的大战，白鹰与重樱的航母编队展开决战。企业等白鹰航母展现了强大的实力，但战争的残酷也让玩家深切感受到——失去伙伴的痛苦。

### 第五章：堕落之翼

重樱内部出现分歧，部分舰娘开始质疑与塞壬合作的决定。铁血方面，俾斯麦的态度也变得微妙。赤色中轴内部并非铁板一块。

### 第六章：坠落的苍蓝

塞壬开始大规模行动，展现出压倒性的科技实力。碧蓝航线与赤色中轴都意识到，塞壬才是人类真正的敌人。然而，双方积怨已深，能否放下成见联手抗敌？

### 第七章：深海的迷途者

剧情深入到塞壬的起源之谜。玩家开始接触到「META」（余烬）的概念——来自不同时间线的舰娘，她们因世界被毁灭而踏上了复仇之路。

### 第八章：交汇的轨迹

碧蓝航线与赤色中轴的冲突达到高潮，但关键时刻，更大的危机降临。塞壬的「观察者」「仲裁者」等高级单位现身，揭示了这场战争只是一场「实验」的冰山一角。

## 游戏特色

### 良心运营

- **零氪友好**：被玩家称为「良心航线」，不氪金也能全图鉴
- **高爆率**：建造爆率高，有保底机制
- **资源获取稳定**：日常活动奖励丰厚
- **维护补偿**：维护经常有大量补偿

### 厨力满满

- **400+ 角色**：每位都有独立立绘和语音
- **Live2D**：动态立绘，触摸互动
- **誓约系统**：与喜欢的舰娘结婚
- **后宅互动**：日常生活中的小确幸

### 豪华声优

汇聚上坂堇、雨宫天、茅野爱衣、佐仓绫音、钉宫理惠等众多一线声优。

### 衍生作品

- **TV动画**：《碧蓝航线》TV动画、《碧蓝航线 微速前进！》、《碧蓝航线 Queen's Orders》
- **漫画**：多部官方漫画连载
- **小说**：官方小说化作品
- **主机游戏**：《碧蓝航线 Crosswave》（PS4/NS/PC）
- **联动活动**：与众多 IP 联动，如《莱莎的炼金工房》《传颂之物》等

## 新手指南

### 初始舰娘选择

- **拉菲**：高爆发输出，适合喜欢贴脸输出的玩家
- **标枪**：高机动高闪避，适合操作型玩家
- **Z23**：均衡型，炮击输出优秀

### 前期发展建议

1. **先推主线**：优先推进主线剧情，解锁更多功能
2. **练低耗队**：培养省油的低等级舰队，用来刷图
3. **活动优先**：限时活动奖励丰厚，不要错过
4. **不要急着大建**：积累资源，等限定池再抽
5. **加入大舰队**：获取更多资源和社交乐趣

### 常见术语

| 术语 | 含义 |
|------|------|
| 建造 / 大建 | 消耗资源建造新舰娘 |
| 打捞 | 在关卡中刷怪获取舰船掉落 |
| 布里 | 通用突破材料，有金布里和紫布里 |
| 油耗 | 石油消耗，出击需要消耗石油 |
| 婚舰 | 已经誓约的舰娘 |
| 改造/改二 | 舰船现代化改造，大幅提升实力 |
| 科研 | 科研系统，研发更强的舰船 |
| META/余烬 | 来自其他时间线的黑化舰娘 |
