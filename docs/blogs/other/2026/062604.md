## 什么是 OpenClaw

OpenClaw 是一个开源跨平台游戏引擎重实现项目，旨在完美重现 1997 年经典平台冒险游戏 **Captain Claw（船长克劳/虎胆龙威）**。通过 C++ 现代重构，它不仅保留了原汁原味的操作手感，更赋予了游戏跨平台运行、高清渲染及高度可定制化的现代特性。

简单来说，OpenClaw 不是模拟器，而是用现代技术重新编写的游戏引擎，能够直接读取原版游戏的数据文件，让经典在现代系统上重获新生。

## 核心特性

### 1. 1:1 原版逻辑复刻

通过对原始游戏数据的深度解析，OpenClaw 实现了对原版逻辑的精准还原：

- 角色跳跃弧度、物理碰撞反馈与原作一致
- 敌人 AI 巡逻路径完全复刻
- 所有原版游戏技巧和秘籍仍然适用
- 运行效率大幅提升，告别旧系统兼容性问题

### 2. 现代图形渲染

摆脱 640x480 的限制，支持现代显示技术：

- **宽屏支持**：自定义分辨率，告别黑边
- **多种渲染后端**：OpenGL、Software 渲染
- **平滑缩放**：高质量图像缩放算法
- **高帧率支持**：支持 60Hz、144Hz 显示器

### 3. 全平台操作兼容

除了传统键盘操作，还支持各类主流输入设备：

- **手柄支持**：Xbox、PS、Switch Pro 等
- **自定义按键映射**：自由定义按键位置
- **低输入延迟**：优化的输入处理，适合速通玩家
- **多平台支持**：Windows、Linux、macOS

### 4. 扩展与 Mod 支持

- **自定义关卡**：支持 Claw Map Editor 制作的第三方关卡
- **存档系统**：多存档槽位，支持云端同步备份
- **高清音轨**：支持 MIDI 和数字音轨自由切换
- **社区 MOD**：丰富的玩家制作内容

## 安装方法

### 准备工作：获取原版游戏资源

**重要提示**：OpenClaw 是开源引擎，不包含原版游戏的受版权保护资源。你需要拥有原版游戏的素材文件才能运行。

你需要准备的文件：
- `CLAW.REZ` - 主资源包（包含关卡、图像、音频等）
- 其他 `.REZ` 文件（如果有扩展包）

将这些文件放在一起，稍后配置引擎时会用到。

### Windows 安装

#### 方法一：下载预编译版本（推荐新手）

1. 访问 OpenClaw 官方发布页面
2. 下载最新的 Windows 版本（`.zip` 格式）
3. 解压到任意目录，例如 `C:\Games\OpenClaw\`
4. 将原版游戏的 `CLAW.REZ` 文件复制到同一目录
5. 双击 `openclaw.exe` 启动游戏

#### 方法二：使用包管理器

```powershell
# 使用 Scoop 安装
scoop install openclaw

# 使用 Chocolatey 安装
choco install openclaw
```

### Linux 安装

#### Ubuntu / Debian

```bash
# 添加 PPA 源（如果有）
sudo add-apt-repository ppa:openclaw/stable
sudo apt update
sudo apt install openclaw
```

#### 下载 AppImage（通用方法）

```bash
# 下载 AppImage
wget https://github.com/pman6/OpenClaw/releases/latest/download/OpenClaw-x86_64.AppImage

# 添加执行权限
chmod +x OpenClaw-x86_64.AppImage

# 运行
./OpenClaw-x86_64.AppImage
```

#### Arch Linux

```bash
# 从 AUR 安装
yay -S openclaw-git
```

### macOS 安装

```bash
# 使用 Homebrew 安装
brew install --cask openclaw

# 或下载 .dmg 文件手动安装
# 挂载后将 OpenClaw 拖入应用程序文件夹
```

## 基础使用

### 首次启动配置

1. **启动游戏**：运行 OpenClaw 程序
2. **设置资源路径**：
   - 如果 `CLAW.REZ` 在同一目录，会自动识别
   - 否则在设置中指定资源文件路径
3. **调整显示设置**：
   - 设置 → 显示 → 选择分辨率
   - 开启/关闭全屏模式
   - 选择渲染器（OpenGL/Software）
4. **配置控制器**：
   - 设置 → 输入 → 配置按键
   - 支持键盘和手柄

### 主菜单介绍

### 游戏存档

OpenClaw 提供灵活的存档系统：

- **快速存档**：按 F2 即时保存，F3 读取
- **手动存档**：在暂停菜单中选择保存/读取
- **多存档槽**：支持多个存档位，方便不同进度
- **自动存档**：关卡切换时自动保存

存档文件位置：
- **Windows**：`%APPDATA%\OpenClaw\saves\`
- **Linux**：`~/.local/share/OpenClaw/saves/`
- **macOS**：`~/Library/Application Support/OpenClaw/saves/`

## 配置详解

### 配置文件位置

- **Windows**：`%APPDATA%\OpenClaw\config.ini`
- **Linux**：`~/.config/OpenClaw/config.ini`
- **macOS**：`~/Library/Preferences/OpenClaw/config.ini`

### 主要配置项

```ini
[Graphics]
# 分辨率设置
width = 1920
height = 1080
fullscreen = true
vsync = true

# 渲染器选择：opengl / software
renderer = opengl

# 图像缩放质量：nearest / linear / best
scale_quality = best

# 宽屏模式：保持原始比例 / 拉伸 / 自适应
widescreen = aspect

[Audio]
# 音量设置（0-100）
music_volume = 80
sfx_volume = 90
voice_volume = 100

# 音轨类型：midi / digital
music_type = digital

[Input]
# 控制器选择
controller_type = auto

# 按键映射（键盘）
key_up = Up, W
key_down = Down, S
key_left = Left, A
key_right = Right, D
key_jump = Space, Z
key_attack = X, J
key_run = Shift
key_crouch = Ctrl

[Gameplay]
# 游戏速度（原版为 1.0）
game_speed = 1.0

# 无敌模式（作弊）
god_mode = false

# 显示 FPS
show_fps = false

# 语言设置
language = auto
```

## 开发者指南

### 从源码编译

如果你想自己编译 OpenClaw，可以按照以下步骤操作。

#### 环境准备

**依赖库：**
- SDL2
- SDL2_image
- SDL2_mixer
- SDL2_ttf
- CMake（构建工具）
- C++17 编译器（GCC 8+、Clang 7+、MSVC 2019+）

#### Windows 编译（MSVC）

```powershell
# 1. 克隆仓库
git clone https://github.com/pman6/OpenClaw.git
cd OpenClaw

# 2. 安装依赖（使用 vcpkg）
vcpkg install sdl2 sdl2-image sdl2-mixer sdl2-ttf

# 3. 创建构建目录
mkdir build
cd build

# 4. 配置 CMake
cmake .. -DCMAKE_TOOLCHAIN_FILE=C:/vcpkg/scripts/buildsystems/vcpkg.cmake

# 5. 编译
cmake --build . --config Release
```

#### Linux 编译

```bash
# 1. 安装依赖（Ubuntu/Debian）
sudo apt update
sudo apt install build-essential cmake git
sudo apt install libsdl2-dev libsdl2-image-dev libsdl2-mixer-dev libsdl2-ttf-dev

# 2. 克隆仓库
git clone https://github.com/pman6/OpenClaw.git
cd OpenClaw

# 3. 编译
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(nproc)

# 4. 安装（可选）
sudo make install
```

#### macOS 编译

```bash
# 1. 安装依赖
brew install cmake sdl2 sdl2_image sdl2_mixer sdl2_ttf

# 2. 克隆并编译
git clone https://github.com/pman6/OpenClaw.git
cd OpenClaw
mkdir build && cd build
cmake .. -DCMAKE_BUILD_TYPE=Release
make -j$(sysctl -n hw.ncpu)
```

## 常见问题

### Q1: 启动时提示找不到 CLAW.REZ 文件？

**解决方案：**

1. 确认你有原版游戏的 `CLAW.REZ` 文件
2. 将文件放在 OpenClaw 程序同一目录
3. 或使用命令行参数指定路径：
   ```bash
   openclaw --rez "C:\Games\Claw\CLAW.REZ"
   ```
4. 检查文件名大小写（Linux/macOS 区分大小写）

### Q2: 游戏运行卡顿或帧率低？

**优化方法：**

1. **降低分辨率**：在设置中调低分辨率
2. **切换渲染器**：从 OpenGL 改为 Software（或反之）
3. **关闭垂直同步**：可能降低输入延迟
4. **使用窗口模式**：有时比全屏更流畅
5. **关闭后台程序**：释放系统资源

### Q3: 手柄无法识别怎么办？

**排查步骤：**

1. 确认手柄已正确连接
2. 在设置 → 输入中选择正确的控制器
3. 尝试重新映射按键
4. 更新手柄驱动程序
5. 检查 SDL2 游戏控制器数据库是否支持该手柄

### Q4: 如何在宽屏显示器上正常显示？

**设置方法：**

1. 打开设置 → 显示
2. 将「宽屏模式」设置为：
   - **保持比例**：保持 4:3 比例，两侧黑边（推荐，不变形）
   - **拉伸填充**：拉伸至全屏（画面会变形）
   - **扩展视野**：显示更多游戏内容（部分关卡可能有问题）

### Q5: 存档文件在哪里？如何备份？

**存档位置：**

- Windows：`%APPDATA%\OpenClaw\saves\`
- Linux：`~/.local/share/OpenClaw/saves/`
- macOS：`~/Library/Application Support/OpenClaw/saves/`

**备份方法：** 直接复制整个 `saves` 文件夹即可。

### Q6: 为什么有些关卡玩不了？

可能的原因：

1. **未解锁**：需要按顺序通关才能解锁后续关卡
2. **缺少资源**：扩展关卡需要对应的 `.REZ` 文件
3. **文件损坏**：检查资源文件是否完整
4. **版本不兼容**：确保 OpenClaw 版本支持该资源格式

### Q7: 如何切换到中文界面？

OpenClaw 支持 UTF-8 编码：

1. 如果原版资源包含中文文本，会自动显示
2. 可以安装中文语言包 Mod
3. 在配置文件中设置：`language = zh-CN`
