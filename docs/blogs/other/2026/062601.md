## 什么是 Git

Git 是一个免费、开源的分布式版本控制系统，用于追踪文件变化、协调多人协作开发。无论是个人项目还是团队协作，Git 都是必备的开发工具。

<!-- more -->

## 安装 Git

### Windows
从 [Git 官网](https://git-scm.com/) 下载安装包，一路下一步即可。安装完成后，在任意文件夹右键点击 "Git Bash Here" 即可打开 Git 命令行。

### macOS
```bash
brew install git
```

### Linux
```bash
# Ubuntu/Debian
sudo apt install git

# CentOS/RHEL
sudo yum install git
```

安装完成后，验证版本：
```bash
git --version
```

## 基础配置

安装完成后，首先需要配置用户名和邮箱，这些信息会出现在每次提交记录中：

```bash
git config --global user.name "你的名字"
git config --global user.email "你的邮箱@example.com"
```

查看配置：
```bash
git config --list
```

## 基本概念

| 概念 | 说明 |
|------|------|
| **工作区** (Working Directory) | 你在电脑里能看到的目录，直接编辑文件的地方 |
| **暂存区** (Staging Area) | 临时存放改动的区域，位于 `.git/index` |
| **本地仓库** (Local Repository) | 位于本地的版本库，所有提交记录都在这里 |
| **远程仓库** (Remote Repository) | 托管在 GitHub/GitLab 等服务器上的仓库 |

## 常用操作

### 1. 初始化仓库

```bash
# 在当前目录创建一个新的 Git 仓库
git init

# 克隆一个已有的远程仓库
git clone https://github.com/username/repo.git
```

### 2. 查看状态

```bash
# 查看工作区和暂存区的状态
git status

# 查看简化版状态
git status -s
```

### 3. 添加文件到暂存区

```bash
# 添加单个文件
git add filename.txt

# 添加所有文件
git add .

# 添加指定类型的文件
git add *.js
```

### 4. 提交到本地仓库

```bash
# 提交暂存区内容，-m 后跟提交信息
git commit -m "提交说明"

# 快速提交（跳过 git add，只提交已跟踪的文件）
git commit -am "提交说明"

# 修改上一次提交
git commit --amend
```

### 5. 查看提交历史

```bash
# 查看完整的提交历史
git log

# 查看简化版历史（一行一个提交）
git log --oneline

# 查看带分支图的历史
git log --oneline --graph --all

# 查看最近 n 条提交
git log -n 5
```

### 6. 查看差异

```bash
# 查看工作区与暂存区的差异
git diff

# 查看暂存区与最新提交的差异
git diff --cached

# 查看两个提交之间的差异
git diff commit1 commit2
```

## 分支操作

分支是 Git 最强大的功能之一，允许你在不同分支上并行开发。

### 创建与切换分支

```bash
# 列出所有本地分支
git branch

# 创建新分支
git branch feature-name

# 切换到指定分支
git checkout feature-name

# 创建并切换到新分支（等价于上面两条命令）
git checkout -b feature-name

# Git 2.23+ 推荐使用 switch
git switch -c feature-name
```

### 合并分支

```bash
# 切换到目标分支（如 main）
git checkout main

# 将 feature-name 分支合并到当前分支
git merge feature-name

# 变基（另一种合并方式，提交历史更线性）
git rebase main
```

### 删除分支

```bash
# 删除已合并的分支
git branch -d feature-name

# 强制删除未合并的分支
git branch -D feature-name
```

## 远程仓库操作

### 关联远程仓库

```bash
# 查看已关联的远程仓库
git remote -v

# 添加远程仓库
git remote add origin https://github.com/username/repo.git

# 修改远程仓库地址
git remote set-url origin https://github.com/username/repo.git
```

### 推送与拉取

```bash
# 将本地分支推送到远程仓库
git push origin main

# 首次推送并建立追踪关系
git push -u origin main

# 拉取远程代码并合并
git pull origin main

# 只拉取不合并
git fetch origin
```

## 撤销操作

### 撤销工作区的修改

```bash
# 丢弃单个文件的修改
git checkout -- filename.txt

# 丢弃所有修改
git checkout -- .
```

### 撤销暂存区的文件

```bash
# 将文件从暂存区撤回工作区
git reset HEAD filename.txt

# 撤回所有暂存的文件
git reset HEAD
```

### 撤销提交

```bash
# 软撤销（撤销提交，但保留修改在暂存区）
git reset --soft HEAD~1

# 混合撤销（默认，撤销提交，保留修改在工作区）
git reset --mixed HEAD~1

# 硬撤销（彻底撤销，丢弃所有修改！慎用）
git reset --hard HEAD~1
```

::: warning
`git reset --hard` 会彻底丢弃修改，无法恢复，请谨慎使用！
:::

## 标签操作

标签用于标记重要的版本节点，如 v1.0.0。

```bash
# 列出所有标签
git tag

# 创建轻量标签
git tag v1.0.0

# 创建带说明的标签
git tag -a v1.0.0 -m "Release 1.0.0"

# 推送标签到远程
git push origin v1.0.0

# 推送所有标签
git push origin --tags

# 删除本地标签
git tag -d v1.0.0

# 删除远程标签
git push origin --delete v1.0.0
```

## 常用工作流

### 功能分支工作流

1. 从 main 分支创建功能分支
2. 在功能分支上开发
3. 开发完成后合并回 main
4. 删除功能分支

```bash
git checkout main
git checkout -b feature-login
# ... 开发 ...
git add .
git commit -m "完成登录功能"
git checkout main
git merge feature-login
git branch -d feature-login
```

## 常见问题

### 1. 忽略文件

在项目根目录创建 `.gitignore` 文件，写入不需要追踪的文件或目录：

```
node_modules/
dist/
.env
*.log
.DS_Store
```

### 2. 查看某行代码是谁写的

```bash
git blame filename.txt
```

### 3. 临时保存修改（stash）

当你正在开发但需要切换分支时，可以用 stash 暂存修改：

```bash
# 暂存当前修改
git stash

# 查看暂存列表
git stash list

# 恢复最新的暂存
git stash pop

# 恢复指定的暂存
git stash apply stash@{0}

# 删除最新的暂存
git stash drop
```

## 总结

掌握以上 Git 命令足以应对日常开发中的大部分场景。Git 功能强大，还有很多高级用法等待你去探索。记住，**多练才能熟练**，不要害怕出错，Git 提供了丰富的撤销机制来保护你的代码。
