    Git 使用教程

    霒蚀君 6/26/2026 git版本控制

    # 什么是 Git

    Git 是一个免费、开源的分布式版本控制系统，用于追踪文件变化、协调多人协作开发。无论是个人项目还是团队协作，Git 都是必备的开发工具。

    # 安装 Git

    # Windows

    从 Git 官网 (opens new window) 下载安装包，一路下一步即可。安装完成后，在任意文件夹右键点击 "Git Bash Here" 即可打开 Git 命令行。

    # macOS

    brew install git
    1

    # Linux

    # Ubuntu/Debian
sudo apt install git

# CentOS/RHEL
sudo yum install git

    安装完成后，验证版本：

    git --version

    # 基础配置

    安装完成后，首先需要配置用户名和邮箱，这些信息会出现在每次提交记录中：

    git config --global user.name "你的名字"
git config --global user.email "你的邮箱@example.com"
    1
    2

    查看配置：

    git config --list
    1

    # 基本概念

    概念 说明
    工作区 (Working Directory) 你在电脑里能看到的目录，直接编辑文件的地方
    暂存区 (Staging Area) 临时存放改动的区域，位于 .git/index
    本地仓库 (Local Repository) 位于本地的版本库，所有提交记录都在这里
    远程仓库 (Remote Repository) 托管在 GitHub/GitLab 等服务器上的仓库

    # 分支操作

    分支是 Git 最强大的功能之一，允许你在不同分支上并行开发。

    # 创建与切换分支

    # 列出所有本地分支
git branch

# 创建新分支
git branch feature-name

# 切换到指定分支
git checkout feature-name

# 创建并切换到新分支（等价于上面两条命令）
git checkout -b feature-name

# Git 2.23+ 推荐使用 switch
git switch -c feature-name

    # 撤销操作

    # 撤销工作区的修改

    # 丢弃单个文件的修改
git checkout -- filename.txt

# 丢弃所有修改
git checkout -- .

    # 撤销暂存区的文件

    # 将文件从暂存区撤回工作区
git reset HEAD filename.txt

# 撤回所有暂存的文件
git reset HEAD

    # 撤销提交

    # 软撤销（撤销提交，但保留修改在暂存区）
git reset --soft HEAD~1

# 混合撤销（默认，撤销提交，保留修改在工作区）
git reset --mixed HEAD~1

# 硬撤销（彻底撤销，丢弃所有修改！慎用）
git reset --hard HEAD~1

    # 标签操作

    标签用于标记重要的版本节点，如 v1.0.0。

    # 列出所有标签
git tag

# 创建轻量标签
git tag v1.0.0

# 创建带说明的标签
git tag -a v1.0.0 -m "Release 1.0.0"

# 推送标签到远程
git push origin v1.0.0

# 推送所有标签
git push origin --tags

# 删除本地标签
git tag -d v1.0.0

# 删除远程标签
git push origin --delete v1.0.0

    # 功能分支工作流

    1. 从 main 分支创建功能分支
    2. 在功能分支上开发
    3. 开发完成后合并回 main
    4. 删除功能分支

git checkout -b feature-login
# ... 开发 ...

    # 常见问题

    # 1. 忽略文件

    在项目根目录创建 .gitignore 文件，写入不需要追踪的文件或目录：

    node_modules/
dist/
.env
*.log
.DS_Store

    # 2. 查看某行代码是谁写的

    git blame filename.txt
    1

    # 3. 临时保存修改（stash）

    当你正在开发但需要切换分支时，可以用 stash 暂存修改：

    # 暂存当前修改
git stash

# 查看暂存列表
git stash list

# 恢复最新的暂存
git stash pop

# 恢复指定的暂存
git stash apply stash@{0}

# 删除最新的暂存
git stash drop

    # 总结

    掌握以上 Git 命令足以应对日常开发中的大部分场景。Git 功能强大，还有很多高级用法等待你去探索。记住，多练才能熟练，不要害怕出错，Git 提供了丰富的撤销机制来保护你的代码。
